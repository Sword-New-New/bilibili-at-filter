# B站评论 @ 过滤

一个只做两条过滤规则的浏览器扩展，适合希望简单过滤 B 站评论的用户。

1. 评论以“回复 @”开头时保留，兼容无空格或多个空格。
2. 其余评论正文包含半角 `@` 时隐藏。

无需油猴，无设置面板，安装后自动生效。

| 评论正文示例 | 结果 |
| --- | --- |
| `@小明 快来看这个视频` | 隐藏 |
| `笑死我了 @小红` | 隐藏 |
| `这个解释很清楚，学到了。` | 保留 |
| `回复 @小明：确实如此。` | 保留 |
| `回复@小明：也可以问问 @小红` | 保留 |

只检查评论正文，不匹配昵称。**主楼命中过滤规则时，整串评论（包括它下面的所有回复）一起隐藏。** 主楼保留时，楼中楼回复各自按上述两条规则判断。以“回复 @”开头的评论，即使后面还有其他 `@` 也保留，但仍会随被隐藏的主楼一起隐藏。这个工具按文字过滤，不识别机器人。

## 下载与安装

适用于桌面版 Chrome / Edge，尚未上架扩展商店。

**[下载插件 ZIP](https://github.com/Sword-New-New/bilibili-at-filter/raw/refs/heads/main/dist/bilibili-at-filter.zip)** · [查看发布版本](https://github.com/Sword-New-New/bilibili-at-filter/releases)

1. 点击上方“下载插件 ZIP”，下载 `bilibili-at-filter.zip`，解压到一个固定位置。
2. 在浏览器地址栏输入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
3. 打开“开发者模式”或“开发人员模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `bilibili-at-filter` 文件夹。
5. 刷新已打开的 B 站页面。

选择的是解压后的文件夹，不是 ZIP 或其中的单个文件。安装后请保留该文件夹，不要移动或删除。

如果下载了 GitHub 的源码 ZIP，解压后选择包含 `manifest.json` 的那一层文件夹即可。

更新已安装的版本：用新版文件覆盖原插件目录，在扩展管理页点击该插件的“重新加载”，然后刷新 B 站页面。v1.0.1 起，主楼命中时会连同其下所有回复一起隐藏。

## 使用与停用

没有额外设置，安装后自动过滤。想恢复显示时，在浏览器扩展管理页关闭或卸载扩展，再刷新 B 站页面。

## 隐私与适用范围

- 仅改变你自己看到的页面，不会删除、举报或拉黑他人的评论或账号。
- 插件不发送网络请求，不上传或存储评论数据。
- 仅在 `www.bilibili.com`、`t.bilibili.com` 和 `space.bilibili.com` 页面运行。
- 适配使用 `bili-comments` 组件的网页评论区。B 站改版或其他扩展替换评论区后，可能需要调整适配。

## 关于这个工具

不同意见很正常。这个工具只是提供一种自行过滤评论的选择，减少不必要的争吵，不判断谁对谁错，也不代表作者在相关争议中的立场。

插件由 GPT-6-astra 协助制作。
